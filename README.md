A dependency-free Markdown to HTML renderer, byte-identical to marked 18.1.3 with default options (GFM on). It walks the block grammar once into compact nodes while collecting link reference definitions, then renders inline content straight to HTML with an index cursor — no token tree, no per-token objects.

## Run it

```sh
MAKEFUN_INPUT_DIR=./practice/input MAKEFUN_OUTPUT_DIR=./out node main.ts
```
